# 📱 抖音去水印小程序 - 配置使用说明

## 🎯 功能特点

- ✅ **专业抖音解析**：直接调用 `https://api1.lingjing235.cn/api/douyin/parse` 接口
- ✅ **自动去水印**：解析后的视频已完全去除水印
- ✅ **代理访问**：自动处理防盗链，确保视频正常播放和下载
- ✅ **直接播放**：小程序内可直接播放无水印视频
- ✅ **一键保存**：支持保存到手机相册
- ✅ **智能提取**：自动从分享文本中提取抖音链接

## 🔧 配置要求

### 1. 域名白名单配置
在微信小程序后台（https://mp.weixin.qq.com）配置以下域名：

**request合法域名**：
```
https://api1.lingjing235.cn
```

**downloadFile合法域名**：
```
https://api1.lingjing235.cn
```

### 2. 权限配置
确保小程序已申请以下权限：
- `scope.writePhotosAlbum` - 保存图片和视频到相册

## 🚀 使用方法

### 用户操作流程：
1. **复制分享内容**：在抖音APP中点击分享→复制链接
2. **粘贴到小程序**：打开小程序，粘贴完整的分享文本
3. **自动解析**：系统自动提取抖音链接并解析
4. **观看/保存**：可直接播放或保存到相册

### 开发者集成示例：

```javascript
// 引入工具库
const { parseDouyinVideo, downloadVideoWithProxy } = require('../../utils/douyin.js')

// 解析抖音视频
try {
  const videoData = await parseDouyinVideo(shareContent)
  console.log('解析成功:', videoData)
  // videoData.proxyVideoUrl 可直接用于播放
} catch (error) {
  console.error('解析失败:', error.message)
}

// 下载视频
try {
  await downloadVideoWithProxy(videoUrl, title)
  wx.showToast({ title: '保存成功', icon: 'success' })
} catch (error) {
  console.error('下载失败:', error.message)
}
```

## ⚠️ 重要注意事项

### 1. 必须使用代理
```javascript
// ❌ 错误 - 直接使用原始链接会403
<video src="{{videoData.videoUrl}}"></video>

// ✅ 正确 - 使用代理链接
<video src="{{videoData.proxyVideoUrl}}"></video>
```

### 2. URL编码处理
```javascript
// 必须对原始URL进行编码
const proxyUrl = `https://api1.lingjing235.cn/api/video/proxy?url=${encodeURIComponent(originalUrl)}`
```
