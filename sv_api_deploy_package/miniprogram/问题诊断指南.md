# 🔧 抖音去水印功能问题诊断指南

## 🚨 当前遇到的问题

您遇到的 `request:fail` 错误通常由以下几个原因造成：

## 📋 问题诊断步骤

### 1. 首先点击"测试接口连接"按钮

我已经在页面上添加了一个橙色的测试按钮，点击它可以：
- 测试是否能连接到 `https://api1.lingjing235.cn`
- 显示具体的错误信息
- 确定问题的根本原因

### 2. 根据测试结果进行处理

#### 📱 **情况A：域名访问受限**
**错误信息**：`request:fail domain not in domain list`

**解决方案**：
1. 打开微信小程序后台：https://mp.weixin.qq.com
2. 进入"开发" → "开发管理" → "开发设置"
3. 在"服务器域名"中添加：
   ```
   request合法域名：https://api1.lingjing235.cn
   downloadFile合法域名：https://api1.lingjing235.cn
   ```

#### 🌐 **情况B：网络连接问题**
**错误信息**：`request:fail timeout` 或 `request:fail`

**解决方案**：
1. 检查网络连接是否正常
2. 尝试切换WiFi/4G网络
3. 检查是否有防火墙阻拦

#### 🔒 **情况C：SSL证书问题**
**错误信息**：`request:fail ssl handshake error`

**解决方案**：
1. 确保使用HTTPS协议
2. 检查设备时间是否正确
3. 更新微信开发者工具

#### ⚙️ **情况D：开发工具设置问题**

**解决方案**：
1. 在微信开发者工具中：
   - 点击右上角"详情"
   - 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"
   - 重新编译项目

## 🛠️ 临时调试方案

### 方案1：使用本地代理（开发阶段）

如果外部接口暂时无法访问，可以通过您的后端服务代理：

```javascript
// 修改 utils/douyin.js 中的请求地址
wx.request({
  url: 'https://api1.lingjing235.cn/api/douyin-proxy', // 使用本地代理
  method: 'POST',
  data: {
    originalUrl: 'https://api1.lingjing235.cn/api/douyin/parse',
    params: { url: douyinUrl }
  }
})
```

### 方案2：后端代理实现

在您的服务端添加代理接口：

```javascript
// server/src/routes/douyin-proxy.ts
app.post('/api/douyin-proxy', async (c) => {
  try {
    const { originalUrl, params } = await c.req.json()
    
    const response = await fetch(`${originalUrl}?url=${encodeURIComponent(params.url)}`)
    const data = await response.json()
    
    return c.json(data)
  } catch (error) {
    return c.json({ success: false, error: error.message }, 500)
  }
})
```

## 🔍 详细错误分析

### 错误码对照表

| 错误信息 | 可能原因 | 解决方案 |
|---------|---------|---------|
| `domain not in domain list` | 域名未配置白名单 | 配置域名白名单 |
| `timeout` | 网络超时 | 检查网络连接 |
| `ssl handshake error` | SSL证书问题 | 检查HTTPS设置 |
| `fail` | 通用网络错误 | 检查网络状态 |

### 调试日志查看

打开微信开发者工具控制台，查看以下日志：
```javascript
console.log('提取到的抖音链接:', douyinUrl)
console.log('请求失败详情:', err)
```

## ✅ 验证修复效果

修复后请按以下步骤验证：

1. **点击测试按钮**：确认连接正常
2. **输入测试链接**：使用一个有效的抖音分享链接
3. **查看解析结果**：确认能正常解析视频信息
4. **测试播放功能**：确认视频能正常播放
5. **测试下载功能**：确认能保存到相册

## 🚀 快速解决方案

**最快的解决方法**：

1. **在微信开发者工具中**：
   - 勾选"不校验合法域名"选项
   - 重新编译运行

2. **在正式发布前**：
   - 到小程序后台配置域名白名单
   - 取消"不校验合法域名"选项
